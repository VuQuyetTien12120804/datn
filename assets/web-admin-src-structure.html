Hình 3.x — Cấu trúc thư mục mã nguồn Web Admin (React + TypeScript)

ClinicBooking · web-admin/src/

web-admin/src/ Thư mục nguồn chính của website quản trị
main.tsx Entry point — khởi tạo React, QueryClientProvider, BrowserRouter
App.tsx Routing — khai báo route, bọc RequireAdmin guard
layout/ Khung giao diện chung sau đăng nhập
AdminLayout.tsx Sidebar menu, header, vùng nội dung <Outlet />
pages/ 10 trang chức năng — mỗi module quản trị một file
Dashboard, Appointments, Doctors, Patients… Accounts, Specialties, Services, Rooms, Slots, Messages, Login
api/ Tầng gọi REST API backend
http.ts Axios instance, base URL, JWT interceptor (401 → logout)
auth.ts API đăng nhập admin (adminLogin)
admin.ts API CRUD master data, lịch hẹn, báo cáo, chat CSKH
types.ts Kiểu dữ liệu TypeScript dùng chung
auth/ Quản lý phiên đăng nhập phía client
storage.ts Lưu / đọc token và thông tin admin từ localStorage
ui/ Component và helper tái sử dụng
TableCard, TableShell, EmptyState… appointmentStatus, pageTitles, validators, confirm
theme/ Tuỳ biến giao diện Ant Design
theme.ts Token màu, biến CSS, override component Ant Design
Biến môi trường VITE_API_BASE_URL (mặc định http://localhost:8085) trỏ tới backend; có thể ghi đè bằng file .env trong thư mục web-admin/. Lệnh phát triển: npm run dev · build: npm run build.
